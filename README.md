# Ashwitha Reddy — Personal Portfolio

A responsive personal portfolio website designed and developed to showcase my
background in Computer Science Engineering, technical skills, projects,
internships, certifications, and achievements.

The portfolio focuses on a clean user experience, responsive design, and
practical front-end development using core web technologies.


## About

I am a Computer Science Engineering student interested in software
development, data analysis, machine learning, and building practical
technology solutions.

This portfolio brings together my academic journey, technical projects,
internship experience, and areas of interest in one interactive web
experience.


## Technology Stack

Technology - Usage 

HTML5 - Semantic page structure and content 

CSS3 - Styling, layout, responsive design and visual effects 

Bootstrap - Responsive grid, navigation, cards, buttons and form components 

JavaScript - Interactivity, DOM manipulation, filtering and validation 

Git & GitHub - Version control and source-code hosting 


## Key Features

- Responsive single-page portfolio
- Semantic HTML5 structure
- Responsive navigation using Bootstrap
- About, Education, Skills, Projects and Contact sections
- Interactive project filtering
- Dark / Light mode
- JavaScript-based DOM manipulation
- Contact form with client-side validation
- Project cards with technology details and screenshots
- Responsive layout for desktop, tablet and mobile screens
- GitHub integration
